# Binghui Wu — Personal Academic Website

This is a lightweight, responsive static site prepared for GitHub Pages. It uses plain HTML, CSS, and a small navigation script, so there is no package installation or build step.

## Preview locally

Open `index.html` in a browser, or start a local server from this directory:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Copy the contents of this directory into the root of the intended GitHub Pages repository.
2. In the repository settings, choose **Pages → Deploy from a branch**, select the intended branch, and choose `/ (root)`.
3. Keep the site URL and any custom domain configuration aligned with the repository and account settings. No custom domain is assumed here.

No workflow or repository settings are changed by this project. The original site is the source for academic content and links; confirm publication status before a public release. The CV download uses the latest PDF supplied by Binghui.

## Updating content

Edit the corresponding section in `index.html`. Publications and academic links are intentionally kept as readable HTML for simple direct updates.
